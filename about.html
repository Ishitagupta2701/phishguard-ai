How it works

  1. Feature extraction – each URL is converted into {{ features|length }} numeric features (length, dots, hyphens, IP address, subdomains, suspicious keywords, entropy, ...).
  2. Machine learning – a Random Forest classifier (scikit-learn) trained on labelled phishing / legitimate URLs outputs a phishing probability.
  3. Verdict – ≥ 70% = phishing, 40–69% = suspicious, < 40% = safe.
  4. Explanation – rule-based checks list human-readable warning signs.
  5. Storage – every scan is saved in a SQLite database for history and statistics.
